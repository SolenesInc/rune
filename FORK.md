# SolenesInc/rune

This is attn's own Rune: a library attn changes whenever that makes attn simpler
or better. Apps pin revisions of `main`, which is never rebased or
force-pushed. Upstream, [anomalyco/rune](https://github.com/anomalyco/rune), is
a source of changes we cherry-pick; `dev` mirrors upstream's `dev` and takes no
commits of ours. attn's `docs/internal/rune-fork.md` has the rules.

This file is the ledger. attn's `scripts/rune-bump` runs every test it names and
fails when it does not record a commit on `main` that upstream's `dev` lacks. A
commit records itself by changing this file: it adds or extends its row.

## Our changes

Each row says what the change does, why it lives in Rune rather than in the app,
and the tests that fail without it. Name each test by its path in backticks,
followed by `(macOS)` when it runs only on macOS. Commit the row with the
change. Commits lists, by hash, the commits made before that rule, which did
not change this file; leave it empty for new rows.
