- **Rune no longer supports Windows.** The Win32 platform layer, the DX12 backend and its precompiled shaders, DirectWrite text, Windows notifications, jump lists, taskbar progress, single-instance launches and the custom titlebar's caption buttons and window menu are gone, with the vendored `winit`, `wgpu-hal` and `accesskit_windows` patches; `[patch.crates-io]` keeps only `parley_engine`. Public API that only Windows served went with them: `Cx::caption_color`, `ChromeInsets::trailing`, `Titlebar::CAPTION_BUTTON_WIDTH`, `KeyPlatform::Windows`, `NativeDisplayId::Windows`, `WindowPlacement::restore`, `WindowHandle::flash`, `single_instance`, `release_instance`, `set_locale`, `El::on_spellcheck_languages` and `spell`'s language list (`languages`, `available_languages`, `set_languages`, `language_name`), `render::uber_shader_identity`, `native_surface::windows`, `FontSmoothing::DirectWrite` and `ClearType`, the `text::mask_cache` disk cache, the `alloc-sites` feature, and `rune_notify`'s `Identity`, `register`, `adopt`, `click_from_url`, `serve_activations` and `wait_activation`. macOS, Linux, the web and iOS build as before.
