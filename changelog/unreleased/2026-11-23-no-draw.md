- **`--no-draw` runs a headless script without drawing.** A run steps every frame as usual
  (time, script events, handlers, layout, `on_frame_encoded`, `--trace`, trees) but encodes and
  submits no GPU work, for tests that read only trees. Its trees are byte for byte a drawn run's.
  On lavapipe on 4 cores, `examples/settings`'s `keycaps.json` (493 frames) takes 0.18 s instead
  of about 7 s. It works with `--tree-at` and `--desktop`. It is refused beside `--snap`, `--out`, `--video`,
  `--strip` or `--first-pixels`, on a run that would open a window, and for an app with a
  custom compositor. A run without it is unchanged.
